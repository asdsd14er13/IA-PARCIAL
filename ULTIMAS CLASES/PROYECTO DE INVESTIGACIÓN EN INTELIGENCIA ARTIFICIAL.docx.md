## Inteligencia Artificial

## 1. Propósito del proyecto

Identificar un problema real y relevante, obtener y utilizar datos reales, originales o provenientes de fuentes reales verificables, diseñar y desarrollar una solución basada en Inteligencia Artificial y evaluar rigurosamente su efectividad.

El proyecto deberá presentarse como una investigación aplicada, utilizando la estructura de un artículo científico y documentando simultáneamente el proceso de desarrollo de software.

El resultado esperado del curso no es simplemente un modelo de IA, sino una solución inteligente diseñada, implementada y evaluada mediante un proceso de ingeniería y sustentada como investigación científica.

El proyecto deberá demostrar la siguiente cadena de trazabilidad:

**Problema real → Situación problemática → Problema de investigación →** **Pregunta de investigación → Objetivos → Datos reales → Método → Diseño de la** **solución → Desarrollo → Experimentos → Evaluación → Resultados → Discusión** **→ Conclusiones**

El proyecto **NO** debe limitarse a ejecutar un algoritmo sobre un dataset y presentar su accuracy.

## El estudiante debe demostrar:

1. Que existe un problema real.
2. Que el problema está respaldado por literatura y evidencia.
3. Que los datos utilizados son reales.
4. Que existe una justificación para utilizar IA.
5. Que la solución fue diseñada mediante técnicas de ingeniería.
6. Que el modelo fue desarrollado siguiendo un proceso reproducible.
7. Que la solución fue evaluada experimentalmente.
8. Que los resultados responden a la pregunta de investigación.
9. Que las conclusiones se derivan de los resultados y no de opiniones.
10.Que el trabajo puede ser reproducido por otro investigador.

## 2. Condiciones obligatorias del proyecto

## 2.1. Datos reales

El proyecto deberá utilizar datos que representen un fenómeno, proceso, población, organización, sistema o situación real.

## Se permite

- Datos obtenidos directamente de una organización.
- Datos obtenidos mediante sensores.
- Datos de sistemas reales.
- Datos abiertos gubernamentales.
- Datos científicos.
- Datos de repositorios institucionales.
- Datos provenientes de APIs.
- Datos obtenidos mediante observación o experimentación real.
- Datos de plataformas públicas, siempre que su utilización sea legal y éticamente permitida.
- Datos históricos reales.
- Datos recopilados por los propios estudiantes.
## No se permite como dataset principal

- Datos completamente ficticios.
- Datos generados artificialmente para reemplazar la ausencia de datos reales.
- Datos sintéticos utilizados como si fueran evidencia real.
- Un dataset inventado por el estudiante.
- Copiar un dataset de un tutorial sin plantear un problema de investigación propio.
Los datos sintéticos pueden utilizarse únicamente como complemento para pruebas técnicas, pero nunca como evidencia principal para responder la pregunta de investigación.

## 7. PREGUNTA DE INVESTIGACIÓN

La pregunta debe ser investigable y susceptible de ser respondida mediante datos y experimentación.

Ejemplos:

- ¿En qué medida un modelo de aprendizaje automático permite predecir el riesgo de abandono académico utilizando datos históricos reales de estudiantes universitarios?

## Pregunta → Objetivo → Experimento → Resultado → Conclusión

## 8. OBJETIVO GENERAL

## El objetivo general deberá expresar:

## verbo + solución/proceso + problema + contexto + propósito

Ejemplo: Desarrollar un modelo de aprendizaje automático para predecir el riesgo de abandono académico de estudiantes universitarios utilizando datos históricos reales, con la finalidad de apoyar la identificación temprana de estudiantes en riesgo.

## 8.1. OBJETIVOS ESPECÍFICOS

Los objetivos específicos deberán representar etapas verificables del proyecto.

Ejemplo:

**OE1: Analizar** las características y factores asociados al abandono académico mediante la revisión de literatura y el análisis exploratorio de los datos reales.

**OE2: Diseñar** un proceso de preparación y transformación de los datos que permita construir un conjunto de datos adecuado para el entrenamiento de modelos de aprendizaje automático.

**OE3: Diseñar** e implementar modelos de aprendizaje automático para la predicción del abandono académico.

**OE4 : Evaluar** experimentalmente el desempeño de los modelos mediante métricas apropiadas.

**OE5 : Comparar** los resultados obtenidos y determinar el modelo que presenta el mejor desempeño bajo las condiciones experimentales establecidas.

**OE6 : Implementar** un prototipo funcional que integre el modelo seleccionado para apoyar el proceso de toma de decisiones.

Cada objetivo específico debe producir un **resultado verificable**.

## B. REGLA DE ORO

El proyecto no será evaluado por: "qué tan sofisticado es el algoritmo". Será evaluado por: **qué tan rigurosamente se demuestra que una solución basada en IA resuelve o mejora un problema real.**

Por tanto: **Problema > Datos > Método > Ingeniería > Experimento > Evidencia > Resultados** **> Contribución** y no: **Algoritmo > código > accuracy.**
